# StatBomb Missing Deduction Images

This folder contains the 12 requested WebP assets for `public/images/football/deductions/`.

**Important resolution note:** the source available during this run was a generated 4×3
contact sheet, not 12 separate native-resolution renders. Each panel was cropped into a
separate file and resized to 1024×1024. The files are valid WebP images, but resizing does
not recreate detail lost in the source sheet. For best production quality, generate each
scene individually at 1024×1024 or higher before replacing these interim assets.

These are generated illustrative football scenes, not documentary images of real matches.
