# StatBomb Football UI Assets

Locally stored visual assets for the Collector experience.

## Optimized WebP backgrounds
- `pitch-background-dark.webp`: lightweight pitch texture used on the login and collector shell.
- `locker-room-hero.webp`: Collector dashboard Matchday hero.
- `locker-room-wide.webp`: My Teammates / squad directory banner.
- `stadium-tunnel.webp`: collector assignment detail header.

## Match-card photography
- `stadium-wide.jpg`
- `match-action-1.jpg`
- `match-action-2.jpg`
- `goalkeeper-save.jpg`
- `team-celebration.jpg`

The football visuals are generated, photorealistic illustrations for interface use. They are not photographs of actual Arqam facilities, identifiable athletes, or specific real match events. Operational values and match details are loaded dynamically from the app and are not part of the images.
