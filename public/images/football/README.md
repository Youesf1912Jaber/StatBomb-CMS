# StatBomb Football UI Assets

Locally stored visual assets for the Collector experience.

- pitch-background-dark.jpg: background texture for login and collector pages.
- locker-room-hero.jpg: Collector dashboard matchday hero.
- locker-room-wide.jpg: squad/teammate panels.
- stadium-wide.jpg and stadium-tunnel.jpg: match and assignment headers.
- match-action-1.jpg, match-action-2.jpg, goalkeeper-save.jpg, team-celebration.jpg: match cards.

These are photorealistic AI-generated visual assets derived from the approved reference board. They are not photos of actual Arqam facilities, identifiable athletes, or specific real match events. Operational values and match details remain dynamically sourced from the app.
